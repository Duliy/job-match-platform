说明

🔍 浏览岗位不需要 Key，直接打开「岗位搜索」即可。

🤖 AI 功能需要你自己的 Key：简历解析、岗位智能匹配、简历深度分析会使用 DeepSeek 的 AI 服务，费用由你的 DeepSeek 账户承担（一次匹配约几分钱）。

如何获取 Key

1. 打开 platform.deepseek.com 注册账号

2. 进入「API Keys」页面，点击「创建 API Key」

3. 复制生成的 Key（sk- 开头），粘贴到上方输入框保存

🔒 隐私说明：Key 只保存在你自己浏览器的 localStorage 中，每次请求时直接带给 DeepSeek 使用，平台服务器不会保存你的 Key。
